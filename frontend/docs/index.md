# 接口管理平台

欢迎使用接口管理平台，这是一个功能强大的API管理解决方案。

## 主要功能

- **API文档展示**：清晰展示API接口文档
- **接口权限管理**：精细控制API访问权限
- **团队协作功能**：支持团队成员协同工作
- **版本控制**：管理API的不同版本
- **接口售卖**：将您的API作为服务出售
- **并发量管理**：控制和监控API调用并发量

## 用户角色

- **超级管理员**：系统最高权限，可管理所有资源
- **管理员**：管理特定团队和API资源

## 快速开始

1. 注册账号或使用以下方式登录：
   - 用户名密码登录
   - Google账号登录
   - 微信账号登录

2. 创建您的第一个API
3. 设置权限和访问控制
4. 发布并开始管理您的API

## 技术栈

- 前端：VitePress + TypeScript + Vue3
- 后端：Node.js + Express + TypeScript
- 数据库：MySQL
